# HCOS™ Evidence

## Purpose

`hcos-evidence` is the authoritative repository for evidence governance, evidence stewardship, citation practice, narrative evidence, synthesis methods, and evidence-review workflows across the Human-Centered Operating Systems™ ecosystem.

This repository helps HCOS™ distinguish among external empirical evidence, authoritative guidance, historical and contextual evidence, cultural and lived-experience evidence, organizational evidence, internal HCOS™ framework sources, author interpretation, HCOS™ synthesis, proposed applications, hypotheses, and future research.

> Evidence is not collected simply to support conclusions. Evidence is stewarded to improve understanding.

## Repository Structure

- `architecture/` — how the HCOS™ evidence ecosystem is organized
- `standards/` — mandatory evidence-governance expectations
- `methods/` — how specific evidence activities are performed
- `workflows/` — operational sequences
- `prompts/` — AI-assisted execution prompts
- `templates/` — repeatable documentation records
- `examples/` — practical applications
- `evidence-atlas/` — maps external disciplines and sources to HCOS™ concepts

## Foundational Documents

- HCOS-NES-001 — Narrative Evidence Standard
- HCOS-CIT-001 — Citation and Evidence Integration Standard
- HCOS-EBS-001 — Evidence Boundary Standard
