# Versioning

The repository uses semantic versioning: `MAJOR.MINOR.PATCH`.

## MAJOR

Use when the evidence-governance architecture changes materially, a core standard is replaced, or implementation expectations become incompatible.

## MINOR

Use when adding a new standard, method, workflow, template, prompt, or substantive evidence domain.

## PATCH

Use for citation corrections, wording clarifications, formatting improvements, or metadata repairs.

## Document Status

- Concept
- Foundational Draft
- Review Draft
- Pilot Version
- Approved
- Superseded
- Retired
